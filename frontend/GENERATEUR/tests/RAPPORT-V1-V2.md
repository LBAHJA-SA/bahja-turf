## 1. Qِيسات صحيحة

| المؤشر | التفسير |
|---|---|
| `P1/P2/P3/P4/P5` | نسبة التذاكر التي تحتوي فائز السباق / الثاني / … |
| `Top3-×` (unorderedTop3) | نسبة التذاكر التي تحتوي الفائز + الثاني + الثالث كلها موجودة بغض النظر عن الترتيب |
| `Top3n` (top3Count) | **متوسط عدد الفائز+الصاحب+الثالث من الموجودين فعلاً في تذكرة كل محرك** |
| `4/5` | تذاكر تلتقط ≥ 4 من الخمسة |
| `5/5` | تذاكر تلتقط الخماسي كاملًا |
| `x/5` | متوسط الإصابات من 5 لكل تذكرة |
| `مناظرة V1×V2` (best-of-5 per race) | لكل سباق تُقارن **أفضل تذكرة** لكل محرك على الحين وصولها؛ يفوز المحرك الذي أفضل تذكرته تلتقط أرقهٔات أكبر |
| فواصل الثقة | Wilson (`z = 1.96`) للنسب الثنائية فقط |

لا وجود ل `orderedTop3` — الحذف العلمي:
الـ
V2 لم تُرتّب تذاكرها في موضعها الرسمي، فالمقارنة عبر موضع التذكرة كانت عديمة القيمة.

## 6. حدود وثقة

- n = 180 تذكرة لـTOUS (union) و70 (كل تخصص) — تحت العينة لا يمكّن من التركيز الإحصائي 95٪.
- فواصل الثقة واسعة ±10-12 pts → معظم الفروقات غير كبيرة إحصائيًا.
- **Top3-× = 0 عبر كل الاختبارات** لـ ATTELÉ وTOUS مع V2 — حتى V1 0.0 في ATTELÉ.
- **5/5 منخفض جدًا** (لا تمثلاً إلا في Expert order) — n=0 لكل التخليصات في كل تخصص (n كبير ومهم).
- **ATTELÉ يتمسك بـV1** — أفضل V2-onlyP12 (62.9%) لا يتفوق على V1 [58.6] في نفس القيمة بدون مفامرة.
